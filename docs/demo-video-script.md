# ShareSafe Practice: demo video script (2:30)

Target length **2:30** · about 274 words of narration (about 110 words per minute, an unhurried pace) · captions: [`demo-video-captions.srt`](demo-video-captions.srt) (generated from this script by `scripts/gen-video-docs.py`, so they match word for word).

**Before recording**
- Run `npm run build && npm run preview`, or use the deployed [DEMO_URL]. Clear site data first so you start from the home screen.
- Set the browser zoom to 100% and the window to about 1280×800, and hide bookmarks.
- Have an Android phone on the same Wi-Fi to scan the QR. On localhost the QR points to `localhost`, which a phone can't open, so either record the phone part against the deployed URL, or open the LAN address (`http://<your-ip>:4173`) on the PC so the QR encodes it. The service worker needs HTTPS or localhost, so use the deployed URL for the phone offline segment.
- Turn on system text-to-speech for the read-aloud moment.
- Keep the scenario consistent: get 2 of 6 right in the pre-check and 5 of 6 in the post-check, so the end screen shows +3.
- Only claim what's true. No real-student testing has happened yet, so don't imply it.
